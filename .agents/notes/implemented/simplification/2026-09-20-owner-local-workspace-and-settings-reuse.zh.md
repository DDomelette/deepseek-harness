# Agent Note: 合并重复操作时保留插件所有权

Status: implemented

[English](2026-09-20-owner-local-workspace-and-settings-reuse.md) | 中文

## 问题

MCP 服务器表单重复维护相同的连接字段，Workspace 归档操作则重复维护响应和存储更新。这些副本在同一个包内承担相同的行为。跨插件的相似代码代价不同：共享它们可能耦合独立演进的交互或持久化格式。

## 决策

MCP 添加和编辑表单共享包内连接字段，分别保留校验、密钥处理和持久化。Workspace 命令在控制器内部共享归档错误映射和响应投影。注册表在调用方既有的串行操作内共享归档成员移除；不引入嵌套队列或新的服务 API。归档 id 和时间戳保留[归档详情和时间](../feature/2026-08-21-archived-details-and-archive-times.zh.md)记录的语义。

置顶行和 Workspace 行使用既有的相对时间格式化函数，以及共享的 `StatusDots` 展示原语。该原语接收已排序、已本地化的状态，渲染首个视觉标记，并向屏幕阅读器提供全部标签。状态推导、导航、拖动行为和命令仍归各插件所有。两个插件已依赖 [UI 原语](../../../../packages/client/ui-primitives/README.zh.md)，因此共享此渲染不会新增插件间依赖。这遵循[共享控件决策](../architecture/2026-09-05-shared-client-control-primitives.zh.md)。

三处相似片段保留窄范围的重复检查例外：置顶行和 Workspace 行的交互标记、设置页的失败与重试标记，以及冻结的用量遥测 token 字段。行的所有者具有不同的定位显示和拖动行为；设置页的所有者控制不同的失败显示条件和重试生命周期。遥测行与 token-meter 投影状态是独立版本化的持久化数据。共享其校验器会让一种格式承受未经其授权的另一种格式变更。

## 考虑过的替代方案

**将每个报告的匹配都提取到共享包。** 会话行外壳或重试包装器会增加公共组件 API，却只共享少量标记，实际行为仍留在各调用方。跨包 token schema 会仅因当前数值约束相同而耦合持久化格式。保留这些副本可以维持所有权而不增加依赖。

**保留全部副本以避免耦合。** 包内的表单和归档复用不会引入包关系。状态展示已符合静态、无 Cordis 的 UI 层职责，并集中维护无障碍行为；保留这些副本没有所有权方面的收益。

## 后果

没有插件导入另一个插件的实现。公共命令、持久化字段、本地化标签和可见交互保持不变。既有表单和行测试覆盖其调用方，定向归档测试验证错误传播、其他时间戳保留及幂等写入。行测试验证共享状态组件的无障碍标签。重复检查例外仅限于独立片段，不排除整个文件或包。
