# Agent Note: 基于 Gateway 控制器的本地 Web 功能

Status: implemented

[English](2026-09-06-local-features-on-gateway.md) | 中文

## 问题

本地 Web 功能依赖的 API 和持久化组件已由 Gateway 运行时替代。同时保留两套实现会让会话生命周期和设置写入产生竞争的所有者。

## 决策

本地置顶、归档详情、MCP 管理、技能开关、插件分组和用量记录使用 Gateway Remote 命名空间、API 会话与工作区控制器以及客户端 store。各功能说明保留产品决策依据；本文负责其与当前运行时的集成决策。

API 保留自己创建或恢复的准确 Agent 句柄。永久删除在关闭空闲自有句柄前检查每个级联成员，随后使用持久化且从叶节点开始的清理计划。运行中或其他组件持有的 Agent 会拒绝删除。JSONL 删除与历史日志读取迁移获取同一内核写入锁；删除移除全部代际和附件，但保留锁 inode。普通迁移仍保留历史字节。Windows 加载 Koffi 锁后端，不加载 POSIX 的 fs-ext。

设置变更结果独立于客户端镜像报告服务端接受状态。密钥编辑只指定变动路径。插件分组键区分全局条目和每个预设的条目；分组只改变浏览器显示，不改变服务端启用状态。归档时间戳与归档成员一同传输，推送状态优先于较旧的一元响应。基础组合启用本地用量记录；HTTP 导出在显式配置并启用前保持禁用。

## 替代方案

恢复已移除的 API 代理及客户端运行时会产生两个竞争的状态所有者。恢复 SQLite 会话持久化会绕过当前 JSONL 代际及所有权保证。SQLite 查询索引仍与权威会话存储分离。将乐观镜像视为保存成功的证据会隐藏服务端拒绝。

## 影响

集成使用当前 Gateway 生命周期和存储格式，同时保留本地功能。合并本身不重写现有用户数据。包测试覆盖拒绝与锁所有权、状态顺序及配置写入；真实 Web 组合覆盖 MCP 保存、技能开关、归档恢复和递归删除。在 Windows 和 Linux 中验证依赖平台的文件系统行为。
